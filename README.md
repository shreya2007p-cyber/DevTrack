# DevTrack

An interactive developer productivity dashboard for managing coding projects, tasks, and learning progress.

## Planned Features

- Project and task management
- Kanban-style task board
- Progress statistics and analytics
- Responsive dark-themed dashboard
- Smooth UI animations
- Persistent storage and user accounts in later versions

## Technology Roadmap

- **Foundation:** HTML, CSS, JavaScript
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Animations:** GSAP, AOS, Three.js
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB
- **Deployment:** To be decided
